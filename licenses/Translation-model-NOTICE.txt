This distribution contains a modified representation of the original weights:
encoder and decoder exported to ONNX (opset 17), followed by dynamic unsigned
INT8 weight quantization. Conversion date: 2026-10-22.
The tokenizer model, vocabulary and configuration originate from the same
source revision. SHA-256 values of distributed assets are provided in
Translation-model-manifest.json. The build script is build_translation_model.py
in the accompanying source workspace.
